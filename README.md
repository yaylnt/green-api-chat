# 🟢 GREEN-API Chat

Веб-интерфейс для отправки и получения текстовых сообщений в WhatsApp через сервис [GREEN-API](https://green-api.com/). Внешний вид построен по образцу [WhatsApp Web](https://web.whatsapp.com/). Тестовое задание на должность «Фронтенд разработчик React».

## Что умеет приложение

1. Вход по учётным данным инстанса GREEN-API (`idInstance`, `apiTokenInstance`). Данные проверяются запросом `getStateInstance`, вход возможен только для авторизованного инстанса.
2. Создание нового чата по номеру телефона получателя.
3. Отправка текстовых сообщений (метод [`sendMessage`](https://green-api.com/docs/api/sending/SendMessage/)).
4. Получение ответов в реальном времени (HTTP API, [`receiveNotification`](https://green-api.com/docs/api/receiving/technology-http-api/) + `deleteNotification`).
5. Список чатов с превью последнего сообщения, окно переписки, выход из аккаунта.

По условию задания поддерживаются только текстовые сообщения, интерфейс намеренно минимальный.

## Быстрый старт

### Что нужно подготовить в GREEN-API

1. Зарегистрироваться на [green-api.com](https://green-api.com/) и создать инстанс.
2. Привязать инстанс к WhatsApp (отсканировать QR-код в личном кабинете). Статус инстанса должен быть `authorized`.
3. В настройках инстанса оставить поле `webhookUrl` пустым и включить уведомления о входящих сообщениях: приложение получает их через HTTP API, а не через вебхук.
4. Скопировать `idInstance` и `apiTokenInstance` из личного кабинета.

### Локальный запуск

```bash
git clone https://github.com/yaylnt/green-api-chat.git
cd green-api-chat
npm ci
npm run dev
```

Приложение откроется на http://localhost:5173/. Переменные окружения не нужны: все данные вводятся в форме входа.

## Как пользоваться

1. Откройте приложение и введите `idInstance` и `apiTokenInstance`.
2. Нажмите «+» в списке чатов и введите номер получателя в формате `71234567890` (11 цифр, начинается с 7).
3. Напишите сообщение и отправьте его кнопкой или клавишей Enter.
4. Ответьте на это сообщение с телефона получателя в WhatsApp. Ответ появится в чате в течение нескольких секунд.
5. Кнопка выхода находится в шапке чата.

Входящее сообщение от нового номера автоматически создаёт новый чат в списке.

## Как работает

**Определение хоста API.** У каждого инстанса свой адрес сервера. Он вычисляется из первых четырёх цифр `idInstance`: для `1101234567` запросы идут на `https://1101.api.green-api.com`. Поэтому пользователю не нужно вводить адрес вручную.

**Отправка.** `POST {apiUrl}/waInstance{idInstance}/sendMessage/{apiTokenInstance}` с телом `{ chatId, message }`. `chatId` собирается из номера: `71234567890@c.us`.

**Получение.** Приложение постоянно держит long polling: запрос `receiveNotification` ждёт новое уведомление до 5 секунд. Если оно пришло, входящее текстовое сообщение (`incomingMessageReceived` с типом `textMessage`) добавляется в чат, после чего уведомление удаляется из очереди методом `deleteNotification`. Без удаления очередь не продвигается.

**Состояние.** Чаты и сообщения хранятся в Redux Toolkit (`chatsSlice`). Состояние и данные входа дублируются в `localStorage`, поэтому переживают перезагрузку страницы, но очищаются после логаута.

**Роутинг.** Два маршрута: `/login` и `/chat`. Маршрут `/chat` защищён (`ProtectedRoute`): без авторизации происходит редирект на `/login`.

## Ограничения

- Только текстовые сообщения (как требуется в задании): картинки, файлы, голосовые и прочие типы игнорируются.
- Номер получателя принимается в формате `7XXXXXXXXXX`.
- История переписки берётся только из того, что приложение получило и отправило само: старые диалоги из WhatsApp не подгружаются.
- Приложение работает без собственного бэкенда: запросы уходят напрямую из браузера в GREEN-API, а `apiTokenInstance` хранится в `localStorage` браузера. Для учебного проекта это допустимо, для реального продукта токен нужно прятать за серверным прокси.
